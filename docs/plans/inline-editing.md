# 方案：去掉编辑模式，改为就地编辑 + 连续撤销

> 状态：已实现（2026-11-13，2026-11-14 按试用意见调整）。下面的“待确认”三项都按建议做了。调整的部分：界面上不再显示操作提示和悬停高亮（原文记录在 [in-app-hints.md](../in-app-hints.md)），字段改为从右键菜单和 Edit 菜单添加，照片窗口去掉了状态文字并新增照片注释，各页面支持 ⌫ 删除选中项。

## 背景

当前词条页有"只读 / 编辑"两种模式，问题有两个：

1. **新加的照片不显示**：编辑模式下刷新时不会重新加载词条，否则会把用户踢出编辑模式（`library_page.py` 的 `refresh()`）。副作用是新加的照片和新词条的封面，要等点 ✓ 保存后才出现。
2. **多一步操作**：照片的增、删、禁用本来就是立即保存、可进回收站恢复的，编辑模式只是多了一道开关。

## 总体思路

- 不再有编辑模式。
- 照片操作随时可用，立即生效。
- 文字默认只读，**双击某一项才编辑那一项**，点别处即保存。
- 所有修改都进入一条撤销历史，⌘Z 可连续撤销。

## 文字：双击就地编辑

| 操作 | 效果 |
|---|---|
| 双击名字 / 别名 / 标签 / 字段名 / 字段内容 | 该项变成输入框，光标定位到双击处 |
| 单击**空的**项（别名、标签、空字段、照片注释） | 直接开始填写（没有文字可选，不会误触） |
| 点别处 / Tab / 回车（单行项） | 保存并退出编辑 |
| ⌘回车（多行字段；单独回车是换行） | 保存并退出编辑 |
| Esc | 放弃这次修改，恢复原文 |

- **单击仍然可以选中、复制文字**，只有双击才进入编辑。右键菜单：Copy / Edit… / Remove Field。
- **空的共享字段**以浅灰行显示（内容处写 "—"）。
- 名字不能为空：按回车时提示并保持输入框；点别处时恢复原名。
- **锁定、切换词条或页面时**：正在编辑的那一项先保存。

## 添加、改名、删除字段（去掉编辑模式后）

最初做的是每区末尾一个 “+ Add …” 链接。试用后觉得界面变复杂，参照 Notion、Obsidian 和 macOS 通讯录改为页面上不放按钮：

```
Met at        the 2019 conference
Birthday      —                         ← 空的共享字段，浅灰
─────────────────────────────────       ← 只有存在个人字段时才显示
Phone         555-11
```

1. 右键字段区或 Edit 菜单：Add Field to All Entries（⇧⌘;）或 Add Field to This Entry（⌘;）。
2. 在对应区域末尾原地出现新的一行，光标在字段名处。输入名字，回车或 Tab → 字段建好，光标直接跳到内容；点别处则只建字段。
3. Esc，或名字留空 → 什么都不加。重名（不分大小写）会提示，输入框保持打开。

- **改名**：双击字段名。共享字段改名对所有词条生效。
- **删除**：清空字段名并回车（或点别处）；或右键选 Remove “字段名”，菜单打开期间这一行有浅色底，标明是哪一个字段。删除共享字段要确认（影响所有词条），有内容的词条把内容保留为个人字段。字段没有选中状态，所以 ⌫ 键不删除字段。

## 照片：常驻按钮，立即生效

- Photos 标题行的 **+ – 🚫** 始终显示；新加的照片、封面变化立即可见。
- 拖拽排序始终可用，**松手即保存**。
- 封面规则不变：第一张即封面。
- 添加照片只在有跳过（重复）、无人脸或无法读取时才弹提示。

## 照片窗口里换脸

- **双击某张脸（或下方缩略图）= 改用这张脸匹配**；单击只是悬停高亮，不改任何东西。
- 只有一张脸且正在使用时，不提供选择；被 🚫 关掉的单脸照片，双击那张脸即可重新启用。

## 撤销 / 重做（参照一般 Mac 应用）

- **一条历史**：⌘Z 连续往回撤，⇧⌘Z 往前重做；撤销后做了新修改，被撤销的步骤不能再重做。上限 100 步。
- **Edit 菜单**：显示具体内容，如 "Undo Add 3 Photos" / "Redo Edit Name"，无可撤销时变灰。
- **覆盖范围**：

| 修改 | 撤销时 |
|---|---|
| 名字 / 别名 / 标签 / 字段内容 | 恢复原文 |
| 添加个人字段 / 删除个人字段 | 去掉 / 连同内容放回原位置 |
| 添加共享字段 / 删除共享字段 | 去掉 / 按原 id、原位置放回，各词条内容回到字段里 |
| 字段改名 | 改回原名 |
| 添加照片 | 照片移到回收站（重做时取回） |
| 删除照片 | 从回收站取回，放回原来的位置 |
| 拖拽换序 | 恢复原顺序 |
| 换脸 / 🚫 | 恢复原来用的那张脸 / 重新启用 |
| 新建词条 | 词条移到回收站 |
| 删除词条 | 从回收站取回 |

- 在其他页面按 ⌘Z：切到 Library，显示被撤销的那个词条。
- 正在输入时，⌘Z 撤销的是输入框里的打字（系统惯例）。
- 某一步无法重放（如回收站已被永久清空）：说明原因，并把这一步从历史中去掉，不会只做一半。
- **隐私**：撤销历史只在内存里，锁定或切换数据库时清空。
- 不进撤销历史：导入文件夹、导出、回收站里的"永久删除"。搜索页的确认保留它自己的 Undo 按钮。
- 后台任务进行中、或有对话框打开时，⌘Z 只发出提示音，避免同时改同一个词条。

## 不变的部分

- 头部的 Export… 和 🗑。
- 回收站逻辑：删除照片和词条仍进回收站。
- 加密和存储格式不变；service 只新增了 `drop_global_field` / `reinstate_global_field`、`has_entry`、`in_trash`。

## 测试（已实现）

- 双击进入编辑、回车 / 点别处保存、Esc 恢复、空名字被拒绝；
- 用 "+ Add …" 添加共享和个人字段、重名提示、Esc 不添加；字段改名、删除及其撤销；
- 添加照片后立即出现（含新词条的封面），撤销进回收站、重做取回；
- 拖拽排序立即落盘，⌘Z / ⇧⌘Z；
- 照片窗口单击不换脸、双击才换（图上和缩略图），逐步撤销；
- 跨词条、跨页面连续撤销 5 步再重做，新修改清空重做；
- 回收站清空后撤销给出说明；锁定时正在编辑的内容被保存、撤销历史被清空；
- service：删除共享字段后按原 id、原位置放回。
