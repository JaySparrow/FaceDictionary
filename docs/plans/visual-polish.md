# 方案：界面美化（不改功能）

> 状态：第一、二批已完成（2026-11-14），第三批待定。基于各页面截图的评估，只动外观，不改任何操作方式。

## 参考的范例

| 应用 | 值得借鉴的地方 |
|---|---|
| Things 3（Apple 设计奖） | 大量留白，几乎没有边框，靠字号和字重分层；只用一种强调色；图标是细线单色 |
| macOS 的 Finder、照片（Apple 人机界面指南） | 侧边栏带单色图标，选中项是圆角色块；内容区不套框；缩略图小圆角、间距统一 |
| macOS 通讯录 | 字段名用灰色常规字体靠右，内容用正文字体，两列对齐整齐 |
| Linear | 8 像素网格，层级靠颜色深浅和字重而不是方框，按钮是无边框的小图标 |
| Bear（Apple 设计奖） | 克制的字体层级和配色，信息少而清楚 |

这些应用的共同点：**少框线、一套图标、一种强调色、三四级字号、统一的间距**。

## 现在的主要问题

1. **框太多**：列表、相册、回收站表格、结果卡片、虚线搜索框都有边框，框里套框，画面显得杂。
2. **图标不统一**：🔒、⚙、🗑、🚫 是彩色 emoji（金色锁、拟物垃圾桶），+ – 是文字，Import… / Export… 是文字按钮，风格混在一起。
3. **选中样式有三种**：侧边栏是圆角蓝块，词条列表和历史列表是整行直角蓝条，回收站是表格高亮。
4. **加粗用得太多**：应用名、页面标题、词条名、结果卡片里的人名、字段名、Photos 标题都是粗体，层级反而不清楚。结果卡片的人名几乎和页面标题一样大。
5. **栏与栏之间太挤**：搜索页的 + 紧贴着右栏的“Best matches”，看起来像是右栏的按钮；Library 的 Import… 紧贴词条名；History 的“1 search(es)”悬在两栏之间。
6. **左边缘没对齐**：词条页里名字、标签、字段名、“Photos”标题的左边缘差几个像素。
7. **颜色偏多偏艳**：匹配度条是饱和的红和绿，排名是蓝色圆点，人脸框是绿色，悬停是黄色，加上蓝色选中，同屏颜色很多。
8. **零碎之处**：
   - 侧边栏顶部的 “FaceDictionary” 和窗口标题重复。
   - 空的搜索框是一大块白色虚线框。
   - 历史页的照片在中间悬空，上方空白很大，底部还有一行带模型名称的说明。
   - 封面的黑色粗框偏重。

## 建议（按收益排序）

### 第一批：收益大、风险小（已完成）

实现：图标是 `common.line_icon()` 里按 24 格自绘的细线图标（加、减、禁用、垃圾桶、设置、锁、导入、导出），没有引入外部文件；间距常量 `PAGE_MARGIN`、`GUTTER`、`GAP` 在 `common.py`；另外隐藏了分栏的拖拽圆点和底部状态栏的分隔线。

| 改动 | 说明 |
|---|---|
| 统一图标 | 用一套细线单色图标（如 Lucide，ISC 许可）替换所有 emoji 和文字符号按钮。统一 16 px，无边框按钮。Import… / Export… 也换成图标 + 悬停名称。 |
| 去掉框 | 词条列表、历史列表、回收站表格、相册不要边框，直接放在窗口背景上，必要处用细分隔线。结果卡片去掉边框，改用间距和细线分隔。 |
| 统一选中样式 | 所有列表都用侧边栏那种圆角色块（窗口不在前台时变浅灰），与 Finder 一致。 |
| 字体层级 | 只留四级：词条名 22 半粗；页面标题 15 半粗；正文 13 常规；次要信息 11–12 常规灰色。字段名改为灰色常规（像通讯录），人名不再加粗放大。 |
| 间距与对齐 | 统一 8 像素网格：页边距 24，栏间距 24，段落间距 16，行间距 8。词条页所有内容的左边缘对齐到同一条线。 |

### 第二批（已完成）

做的时候加了一条原则：**空白多时，让主体（照片、人名、字段内容）变大，界面框架（按钮、标题）不变**，大小随窗口变化而不是写死。所以除下表外还做了：

- 相册照片按宽度自动排列，约 168 px 起、窗口越宽越大，圆角 8 px，间距 12 px；缩略图改为 400 px 保存（旧的 192 px 缩略图在打开词条时后台补做）。
- 字段区高度跟着内容走（最多半个窗口），相册占剩下的全部空间。
- 词条名 28 半粗，别名 15、标签 13 灰色，字段内容 14；结果卡片的照片 92 px、人名 17；照片窗口约占屏幕的四分之三。
- 去掉了底部状态栏：准备索引的进度和“文件读不出”的警告移到侧边栏底部，忙碌指示变成一条细线。
- 侧边栏选中项是中性灰（导航），内容列表的选中项仍是强调色。
- 空的搜索框是白色圆角区域（没有改成浅灰，白色在灰色窗口上更干净），有照片时去掉底色和边距，照片铺满。
- 之后调整了文字层级：字段名、别名、标签和表格栏名改回正文颜色，灰色只用于提示和注释（不再照搬通讯录的灰色字段名）。

原计划：

| 改动 | 说明 |
|---|---|
| 侧边栏 | 去掉顶部的应用名或改小；每个页面名前加单色图标；背景略深于内容区，与 macOS 侧边栏接近；设置和锁定改为无边框小图标。 |
| 词条列表 | 头像改为圆形（像通讯录）；名字 13 常规，照片数 11 灰色放在同一行右侧或第二行。 |
| 相册 | 缩略图小圆角（6 px），网格间距统一 8 px；封面标记改为强调色细环（2 px），不用黑色粗框。 |
| 搜索结果 | 排名数字改为灰色小字，不用蓝色圆点；匹配度条改细（4 px），数字放在条的右边而不是压在条上；条统一用强调色，只有低置信度时文字变成暗橙色。 |
| 搜索框 | 空的时候改成浅灰底色的圆角区域，不用虚线；有照片后不显示边框。 |
| 历史页 | 照片顶部对齐；去掉底部带模型名称的说明行（和状态栏一致）。 |
| 配色 | 只保留系统强调色；绿色只表示“用于匹配的那张脸”，红色只用于删除。硬编码的黄色提示条、匹配度颜色改为随浅色和深色模式变化。 |

### 第三批

- 检查深色模式下所有自绘元素（封面框、匹配度条、提示条、拖拽提示）的颜色。
- 解锁页：去掉卡片边框，加大留白，Unlock 用强调色的默认按钮样式。

## Qt 的限制

- macOS 原生的半透明侧边栏（毛玻璃）和 SF Symbols 图标 Qt 不直接支持，只能用相近的纯色背景和开源图标集代替。
- 所有改动只涉及样式表、绘制和布局，不改操作方式，现有测试应全部保持通过。
